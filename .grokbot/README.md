# Grok Bot marker

This directory marks a project for the djournal `grok-bot` harness.

Grok Bot has no session hooks. Journal compliance comes from the installed
skills, `AGENTS.md`, and `djournal` / `journal` commands. The Journal Hub
recipe installed with this harness lives at `integrations/grok-bot/`.

Register skills from `integrations/grok-bot/skill-registration.md`. See
`docs/grok-bot.md` in the djournal package for the architecture.
