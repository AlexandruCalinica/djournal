# Peer engineering bot briefing

Send this to each engineering bot named during getting started. Replace the
angle-bracket fields. Keep the message short.

```text
<hub-display-name> can help with the project journal, and you can use it
without waiting for the hub.

Project root: <project-root>
Install (already done when the hub finished setup):
  djournal install --harness grok-bot --target <project-root>

Use the journal skills and the djournal / journal CLI against that root.
Start meaningful work with the journal workflow skill. Resume, plan, research,
decide, and close entries yourself.

<hub-display-name> is an async reconciler. Ask it to run Checkup with Journal
Hub when you want status, share/sync review, or conflict paths. Local-only
work stays unpublished until someone explicitly shares it. There are no Grok
session hooks; skills and the CLI are the integration.
```
